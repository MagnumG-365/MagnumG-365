# Assets Directory

This directory contains visual assets for the GitHub profile README.

## Required Assets

To fully customize your profile, add the following assets:

### Header & Footer
- `gaming-header.gif` - Animated header for the profile (recommended size: 1200x300px)
- `gaming-footer.gif` - Animated footer for the profile (recommended size: 1200x100px)

### Recommended Assets
- Profile banner with gaming theme
- Custom badges and icons
- Achievement images
- Platform logos

## Asset Guidelines

### Size Recommendations
- **Header:** 1200x300px (or similar 4:1 ratio)
- **Footer:** 1200x100px (or similar 12:1 ratio)
- **Icons:** 64x64px or SVG
- **Banners:** 1200x400px

### Format Recommendations
- Use PNG for static images with transparency
- Use GIF for simple animations
- Use WebP for better compression (GitHub supports it)
- Use SVG for scalable graphics

### File Size
- Keep GIFs under 5MB for faster loading
- Optimize images before uploading
- Use compression tools like TinyPNG

## Example Assets

### Placeholder Assets

Until you add custom assets, the profile uses placeholder URLs. To add your own:

1. Create or download gaming-themed assets
2. Add them to this `assets/` directory
3. Update the URLs in `PROFILE_README.md`

The profile currently references:
```markdown
<img src="https://raw.githubusercontent.com/MagnumG-365/MagnumG-365/main/assets/gaming-header.gif" .../>
```

After adding your assets and pushing to GitHub, these URLs will work automatically.

## Quick Start

1. Create or download your gaming header and footer images
2. Rename them to `gaming-header.gif` and `gaming-footer.gif`
3. Add them to this directory
4. Commit and push to GitHub
5. Your profile will automatically display the new assets!
